## Repository Layer (Слой работы с БД)

Данный пакет реализует паттерн **Repository** для работы с PostgreSQL через GORM. Здесь инкапсулирована вся логика SQL-запросов, транзакций, ленивой предзагрузки связей (Preloading) и пакетной вставки данных электронного носа.

### Как использовать в Сервисах / Хендлерах

#### 1. Инициализация в `main.go`
Для удобства все репозитории объединены в единый контейнер `Registry`. Вы можете инициализировать весь слой одной командой сразу после подключения к БД:

```go
db := database.DB() // Получаем инстанс gorm.DB после database.Connect()

// Инициализируем весь слой репозиториев
repos := repository.NewRegistry(db)

```

#### 2. Сохранение эксперимента (Транзакция + Batch Insert)

Метод `CreateFullMeasurement` автоматически упаковывает создание сессии, параметров датчиков и точек временного ряда в **одну атомарную транзакцию** (в случае сбоя база выполнит `ROLLBACK`).

Массив точек автоматически разбивается на пачки (пакеты по 1000 штук) на уровне драйвера, чтобы оптимизировать SQL-запросы для тайм-серий:

```go
err := repos.Measurements.CreateFullMeasurement(ctx, &measurement, paramsArray, dataPointsArray)

```

#### 3. Чтение данных для API и графиков фротенда

* `repos.Measurements.GetAll(ctx)` — возвращает список всех измерений с предзагруженными связями (`Device`, `MeasurementObject`, `User`) для заполнения главной таблицы.
* `repos.Measurements.GetSensorDataPoints(ctx, measID, sensorID)` — возвращает отсортированный хронологически (`time_offset_s ASC`) массив точек конкретного датчика для отрисовки графиков кривых.

#### 4. Работа со справочниками и датчиками (Парсер / Lookups)

Для интеграции с ML-скриптами и парсерами XML доступны методы автоматического поиска или регистрации сущностей «на лету» (`FirstOrCreate`):

```go
// Поиск девайса по его серийнику или коду из XML
device, err := repos.Lookups.GetDeviceByCode(ctx, "MAG8")

// Получение или автоматическое создание датчика/объекта исследования
sensor, err := repos.Sensors.GetOrCreateSensor(ctx, "Sensor_1", coatingID)
object, err := repos.Lookups.GetOrCreateObject(ctx, "Раствор аммиака")

```
